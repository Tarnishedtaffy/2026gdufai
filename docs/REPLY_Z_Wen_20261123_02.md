### Q4. #38 是否覆盖所有影响预算的写路径

**同意扩到全部写路径，不只 PATCH 改 kind。**

`fix/m2-budget-recalc` 覆盖：

1. **导入**：批次成功后按「受影响月份 + 类别集合」重算一次，不逐条重算；
2. **PATCH**：
   - 改 `categoryId` / `kind` / `amountCents` / `occurredAt` 都可能导致月份或类别变化；
   - `occurredAt` 跨月时，要同时重算旧月和新月；
3. **void**：作废后重算对应月份 + 类别；
4. **类别 reassign**：重算源类别与目标类别的相关月份，并处理预算冲突后的告警；
5. 补测试：
   - 跨 kind PATCH 后预算断言；
   - 金额跨越 80 / 100 阈值；
   - void 后告警不重复、不误删；
   - 跨月 PATCH 的旧月/新月告警。

动态聚合不变：不新增 `spent_cents`，不新增迁移 004；重算函数只负责 `budget_alerts`。
